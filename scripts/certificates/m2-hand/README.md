# Generators of the Bernstein certificates for the M2 hand theorems

These Python scripts generated the Lean files
`SmoothedOctagon/Exclusion/Mixed/Hand/Cert{Unit,Order,Strip,Low,HighT}.lean`: exact Bernstein
coefficients (positivity certificates) for the polynomial sign steps of
`MIXED_NONSHORT_REVERSE_HAND_EXCLUSION` and `MIXED_NONSHORT_LOW_SCALE_HAND_EXCLUSION`, which Lean
checks with `ring`. They are kept for reproducibility; Lean does not trust them.
